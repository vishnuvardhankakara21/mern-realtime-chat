# MERN Real-Time Chat Application

A full-stack real-time chat application built with the MERN stack and Socket.IO.

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- Mongoose
- Socket.IO
- JWT
- Axios

## Features

- User authentication
- One-to-one messaging
- Group chats
- Real-time messaging
- Real-time notifications
- REST APIs

## Project Status

This project is being studied, customized, and extended as part of my full-stack development learning.
